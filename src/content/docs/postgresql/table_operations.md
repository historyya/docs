## 常用数据类型

### 数值类型

| 类型             | 存储大小 | 描述                 | 范围                             |
| :--------------- | :------- | :------------------- | :------------------------------- |
| smallint         | 2字节    | 小范围整数           | -32,768 到 +32,767               |
| integer          | 4字节    | 最常用整数           | -2,147,483,648 到 +2,147,483,647 |
| bigint           | 8字节    | 大范围整数           | -9.22e18 到 +9.22e18             |
| decimal(p,s)     | 可变     | 精确小数（财务数据） | 最高精度131,072位                |
| numeric(p,s)     | 可变     | 精确小数             | 同decimal，推荐使用              |
| real             | 4字节    | 单精度浮点数         | 6位十进制精度                    |
| double precision | 8字节    | 双精度浮点数         | 15位十进制精度                   |
| serial           | 4字节    | 自增整数             | 1 到 2,147,483,647               |
| bigserial        | 8字节    | 自增大整数           | 1 到 9.22e18                     |

#### 使用建议

- 普通ID用`integer`或`bigint`
- 金融用`numeric(10,2)` （10位总数，2位小数）
- 自增主键用`serial`或`bigserial`

### 字符串类型

| 类型       | 别名                 | 特点             | 使用场景             |
| ---------- | -------------------- | ---------------- | -------------------- |
| varchar(n) | character varying(n) | 变长，限制长度   | 用户名、标题         |
| char(n)    | character(n)         | 定长，空格填充   | 固定代码（如状态码） |
| text       | -                    | 推荐使用，无限长 | 描述、内容、备注     |
| bpchar     | -                    | 变长，去尾部空格 | 较少使用             |

#### 最佳实践

大多数情况用`text`，有明确长度限制时用`varchar(n)`

### 日期时间类型

| 类型        | 存储大小 | 格式示例                  | 说明            |
| ----------- | -------- | ------------------------- | --------------- |
| date        | 4字节    | 2026-01-15                | 仅日期          |
| time        | 8字节    | 15:30:50.123              | 仅时间          |
| timestamp   | 8字节    | 2026-01-15 15:30:50       | 常用，日期+时间 |
| timestamptz | 8字节    | 2026-01-15T15:30:50+08:00 | 推荐，带时区    |
| interval    | 16字节   | 3 days 02:00:00           | 时间间隔        |

#### 最佳实践

生产环境强烈推荐使用`timestamptz`

### 其他实用类型

| 类型         | 用途       | 示例                                 |
| ------------ | ---------- | ------------------------------------ |
| boolean      | 布尔值     | true/false                           |
| json / jsonb | JSON数据   | {"name": "张三", "age": 30}          |
| uuid         | 唯一标识符 | a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11 |
| array        | 数组       | {1,2,3}, {"a","b","c"}               |
| inet / cidr  | IP地址     | 192.168.1.1                          |

### 列约束

| 约束类型                           | 描述                       | 示例                                                     |
| ---------------------------------- | -------------------------- | -------------------------------------------------------- |
| `NOT NULL`                         | 字段不能为空               | `account TEXT NOT NULL`                                  |
| `NULL`                             | 字段允许为空               | `description TEXT NULL`                                  |
| `DEFAULT`                          | 指定默认值                 | `status BOOLEAN DEFAULT TRUE`                            |
| `PRIMARY KEY`                      | 主键约束，唯一且不能为空   | `id BIGSERIAL PRIMARY KEY`                               |
| `UNIQUE`                           | 唯一约束，不允许重复值     | `email TEXT UNIQUE`                                      |
| `CHECK`                            | 检查约束，必须满足指定条件 | `age INT CHECK (age >= 0)`                               |
| `REFERENCES`                       | 外键约束，引用其他表       | `role_id INT REFERENCES role(id)`                        |
| `GENERATED ALWAYS AS`              | 生成列，由表达式自动计算   | `total NUMERIC GENERATED ALWAYS AS (price * qty) STORED` |
| `GENERATED BY DEFAULT AS IDENTITY` | 自增列（可手动指定值）     | `id BIGINT GENERATED BY DEFAULT AS IDENTITY`             |
| `GENERATED ALWAYS AS IDENTITY`     | 自增列（不允许手动指定值） | `id BIGINT GENERATED ALWAYS AS IDENTITY`                 |

## 数据表操作

### 创建数据表

```sql
-- 创建用户表
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    full_name TEXT NOT NULL,
    age INTEGER,
    email VARCHAR(200) UNIQUE NOT NULL
);
```

```sql
-- 指定模式下创建表
CREATE TABLE IF NOT EXISTS public.products (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,  -- 自增主键
    public_id UUID DEFAULT GEN_RANDOM_UUID(),  -- uuid
    name TEXT NOT NULL,
    price NUMERIC(10,2) NOT NULL CHECK (price > 0),
    stock INTEGER DEFAULT 0 CHECK (stock >= 0),
    is_sale BOOLEAN DEFAULT false,
    created_at TIMESTAMPTZ DEFAULT NOW()  -- 带时区的时间
);

COMMENT ON TABLE products IS '商品表';
COMMENT ON COLUMN products.id IS '主键';
```

### 删除表

```sql

-- 清空表并且重置自增ID

```

## 数据操作CRUD

### 插入数据

```sql
-- 插入单条数据
INSERT INTO users (username, full_name, email, age, hobby) 
VALUES ('zhangsan', '张三', 'zhangsan@example.com', 25, ARRAY['唱歌', '跳舞']);

-- 插入多条数据
INSERT INTO users (username, full_name, email, age, hobby) VALUES
('lisi', '李四', 'lisi@example.com', 28, '{"唱歌","跳舞"}'),
('wangwu', '王五', 'wangwu@example.com', 32),
('zhaoliu', '赵六', 'zhaoliu@example.com', 22);

-- 插入后立刻返回id
INSERT INTO users (account,password)
VALUES ('admin','123456')
RETURNING id;
```

注意：如果插入数据时约束失败，自增id也是会消耗的(+1)。

### 查询数据

```sql
-- 查询所有
SELECT * FROM users;

-- 选择特定列
SELECT id, full_name, email FROM users;

-- 条件查询
SELECT * FROM users WHERE age > 25 AND status >= 1;

-- 模糊查询
SELECT * FROM users WHERE full_name LIKE '张%';
-- ILIKE 不区分大小写
SELECT * FROM users WHERE email ILIKE '%EXample.com';
-- 查询2026年创建的用户
SELECT * FROM users WHERE created_at >= '2026-01-01' AND created_at < '2027-01-01';

-- 数组查询，查询hobby中包含'唱歌'的数据
SELECT * FROM users WHERE '唱歌' = ANY(hobby);
-- 查询同时包含"唱歌"和"游泳
SELECT * FROM users WHERE hobby @> ARRAY['唱歌', '游泳'];
-- 查询hobby包含"唱歌"或"篮球"任意一个
SELECT * FROM users WHERE hobby && ARRAY['唱歌', '篮球'];

-- JSONB查询
-- 查询author是张三的文档。->>返回的是text类型
SELECT * FROM documents WHERE metadata->>'author' = '张三';
-- 查询作者姓名。->返回的是JSONB类型
SELECT * FROM documents WHERE metadata->'author'->>'name' = '张三';
-- 查询price>=100
SELECT * FROM products WHERE (metadata->>'price')::INT >= 100;
-- 查询是否存在author这个key
SELECT * FROM products WHERE metadata ? 'author';

-- ip地址查询
-- 查询某个 IP 是否属于一个网段
SELECT * FROM servers WHERE ip << '192.168.1.0/24';

-- 分页
SELECT * FROM users ORDER BY id LIMIT 10 OFFSET 0;  -- 第1页
SELECT * FROM users ORDER BY id LIMIT 10 OFFSET 10; -- 第2页

-- 聚合函数
-- 统计所有行
SELECT COUNT(*) FROM users;
-- 计算users表中age字段的平均值
SELECT AVG(age) as avg_age FROM users;
-- 统计行数、求和、求平均值、最大值、最小值
SELECT
    COUNT(*) AS total,
    SUM(age) AS sum_age,
    AVG(age) AS avg_age,
    MAX(age) AS max_age,
    MIN(age) AS min_age
FROM users;

-- 分组
-- 按 city 分组，并统计每个城市的人数
SELECT city, COUNT(*) AS user_count FROM users GROUP BY city;
-- 统计每个城市工资总和
SELECT city, SUM(salary) AS total_salary FROM users GROUP BY city;
-- 统计用户数量不少于 10 的城市
SELECT city, COUNT(*) AS total FROM users GROUP BY city HAVING COUNT(*) >= 10;
-- 按照人数排序
SELECT city, COUNT(*) AS total FROM users GROUP BY city ORDER BY total DESC;
```

## 常用函数

### 字符串处理

```sql
-- 拼接字符串
SELECT CONCAT(first_name, ' ', last_name);

SELECT first_name || ' ' || last_name;

-- 大小写转换
-- LOWER：小写，UPPER：大写，INITCAP：每个单词首字母大写
SELECT
    LOWER(name),
    UPPER(name),
    INITCAP(name)
FROM users;

-- 截取字符串
SELECT SUBSTRING('PostgreSQL', 1, 4);  -- Post

-- 替换字符串
SELECT REPLACE('PostgreSQL', 'SQL', 'DB');  -- PostgreDB

-- 如果 nickname 是 NULL 返回 "匿名用户" 否则 返回 nickname
SELECT
    id,
    COALESCE(nickname, '匿名用户') AS nickname
FROM users;
```

### 数值计算

```sql
-- 四舍五入
SELECT
    ROUND(3.1415926,3),  -- 四舍五入：3.14
    FLOOR(3.9),   -- 向下取整：3
    CEIL(3.1),  -- 向上取整：4
    TRUNC(3.14159,2);  -- 截断小数：3.14

SELECT

    SIGN(-100),  -- 符号：-1
    MOD(17,5);  -- 取余：2
```

## 多表关系

### 一对一

使用：外键 + UNIQUE

```sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL
);

CREATE TABLE user_profile (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL UNIQUE,  -- 唯一约束
    avatar TEXT,
    birthday DATE,
    CONSTRAINT fk_profile_user  -- 外键关联
        FOREIGN KEY (user_id)
        REFERENCES users(id)
        ON DELETE CASCADE  -- 级联删除：当users表某一个数据被删除，关联的user_profile中user_id相同的数据也会被删除
);

-- 查询
SELECT *
FROM users u
JOIN user_profile p
ON u.id=p.user_id;
```

### 一对多

使用：外键（不加 UNIQUE）

```sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL
);

CREATE TABLE orders (
    id BIGSERIAL PRIMARY KEY,
    order_no TEXT NOT NULL,
    user_id BIGINT NOT NULL,
    CONSTRAINT fk_orders_user
        FOREIGN KEY (user_id)
        REFERENCES users(id)
        ON DELETE RESTRICT
);

-- 查询
SELECT
    o.id,
    o.order_no,
    u.name
FROM orders o
JOIN users u
ON o.user_id = u.id;

-- 查询张三所有订单
SELECT *
FROM orders
WHERE user_id = 1;

SELECT
    o.*
FROM users u
JOIN orders o
ON u.id = o.user_id
WHERE u.name = '张三';
```

### 多对多

使用：中间关联表

```sql
-- 学生表
CREATE TABLE students (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL
);

-- 课程表
CREATE TABLE courses (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL
);

-- 关联表
CREATE TABLE student_courses (
    student_id BIGINT NOT NULL,
    course_id BIGINT NOT NULL,
    PRIMARY KEY (student_id, course_id),  -- 联合主键
    FOREIGN KEY (student_id)
        REFERENCES students(id)
        ON DELETE CASCADE,
    FOREIGN KEY (course_id)
        REFERENCES courses(id)
        ON DELETE CASCADE
);

-- 查询张三所有课程
SELECT c.*
FROM students s
JOIN student_courses sc
ON s.id = sc.student_id
JOIN courses c
ON sc.course_id = c.id
WHERE s.name = '张三';

-- 查询英语有哪些学生
SELECT s.*
FROM courses c
JOIN student_courses sc
ON c.id = sc.course_id
JOIN students s
ON sc.student_id = s.id
WHERE c.name = '英语';

-- 查询每个学生选了多少门课
SELECT
    s.name,
    COUNT(sc.course_id) AS course_count
FROM students s
LEFT JOIN student_courses sc
ON s.id = sc.student_id
GROUP BY s.id, s.name;
```

## 索引

理解：索引相当于书的目录。假设一本新华字典有2000页，如果想要查“数据库”，没有目录只能一页一页的去找，时间复杂度`O(n)`，有目录，假设数据库在856页，直接翻过去，时间复杂度`O(log n)`。

作用：提高查询速度。

```sql
-- 假设没有索引，会一行一行的扫描，这叫全表扫描
-- 有id索引，直接定位数据，这叫索引扫描
EXPLAIN ANALYZE
SELECT *
FROM users
WHERE id = 1000000;

-- 什么时候需要索引？
-- 如果email经常查询
SELECT *
FROM users
WHERE email='a@test.com';

-- 创建索引
CREATE INDEX idx_users_email
ON users(email);

-- 设置索引为B-tree
CREATE INDEX idx_users_name
ON users
USING btree(name);

-- 建立JSONB 索引
CREATE INDEX idx_books_meta
ON books
USING GIN(metadata);

-- 创建唯一索引
CREATE UNIQUE INDEX idx_users_email
ON users(email);
-- 等价于
ALTER TABLE users
ADD CONSTRAINT uq_email
UNIQUE(email);

-- 删除索引
DROP INDEX idx_users_name;

-- 假如经常需要查询city和age
SELECT *
FROM users
WHERE city='北京'
AND age=20;
-- 建立联合索引
CREATE INDEX idx_city_age
ON users(city, age);
-- 数据库会先查city='北京'再age=20，速度非常快

-- 什么时候不要建索引？
-- 假如gender只要男女两种值，建立索引没有效果，因为数据库还是要扫描一半数据
```

## 事务

:::tip
事务是一组数据库操作的最小执行单元，要么全部成功，要么全部失败。
:::

### 特性 ACID

- 原子性：要么全部执行，要么全部不执行
- 一致性：事务执行前后，数据库必须满足业务规则
- 隔离性：多个事务同时执行时，互不干扰
- 持久性：提交后的数据永久保存

```sql
-- 开启事务
-- 数据库创建事务上下文
BEGIN;
-- 或
-- START TRANSACTION;

-- 执行SQL
UPDATE account
SET balance=balance-100
WHERE id=1;

UPDATE account
SET balance=balance+100
WHERE id=2;

-- 提交事务
COMMIT;

-- 事务回滚
-- 如果执行SQL中有某条SQL执行失败，会进入事务回滚，数据库根据日志恢复
-- ROLLBACK;
```

### 事务中的锁

#### 行锁

```sql
BEGIN;

-- 锁住这一行，其他事务不能修改
SELECT stock
FROM products
WHERE id=1
FOR UPDATE;

-- 库存减一，保证不会超卖
UPDATE products
SET stock=stock-1
WHERE id=1;

COMMIT;
```

### 保存点Savepoint

事务内部部分回滚

```sql
BEGIN;

INSERT INTO users VALUES(1,'张三');

SAVEPOINT sp1;

INSERT INTO users VALUES(2,'李四');

-- 保留张三，撤销李四的sql执行
ROLLBACK TO sp1;

COMMIT;
```

## CTE

```sql
-- 查询订单总金额超过 200 的用户
WITH user_orders AS (
    SELECT
        user_id,
        SUM(amount) AS total
    FROM orders
    GROUP BY user_id
)
SELECT *
FROM user_orders
WHERE total > 200;

--不用CTE
SELECT *
FROM (
    SELECT
        user_id,
        SUM(amount) total
    FROM orders
    GROUP BY user_id
) t
WHERE total > 200;
```

## View

```sql
-- 查询用户订单统计
SELECT
    u.id,
    u.name,
    COUNT(o.id) AS order_count,
    SUM(o.amount) AS total_amount
FROM users u
LEFT JOIN orders o
ON u.id=o.user_id
GROUP BY u.id,u.name;

-- 创建视图
CREATE VIEW user_order_stats AS
SELECT
    u.id,
    u.name,
    COUNT(o.id) AS order_count,
    SUM(o.amount) AS total_amount
FROM users u
LEFT JOIN orders o
ON u.id=o.user_id
GROUP BY u.id,u.name;

-- 查询
SELECT *
FROM user_order_stats;

-- 查询所有视图
SELECT *
FROM information_schema.views;
```
